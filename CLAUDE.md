Read `docs/ROADMAP.md` first ("Read this first"). Work one phase at a time; wait for user confirmation between phases.

## Project facts (verified)
- Vite build output only. Main bundle `assets/index-B2A-NN9Y.js` (minified). Add-ons: `addons/editor.js`, `addons/rally.js` (readable).
- Patch built files directly. Keep `__vite__mapDeps` (top of the main bundle) consistent with any chunk you add or remove.
- Interstate lives in `interstate/` as its own page (Phase 3). Its source of truth was the user's single-file `Interstate.html` (build 1.26).
- `?safe=1` skips saved room scripts and object scripts (Phase 2). The Minimal UI preset it should force comes with UI Settings (Phase 5).
- `/__studio/session` 404 on a static host is expected (a dev-server probe in the bundle).
- Serve locally: `python3 -m http.server` in this folder, open `index.html`.

### Phase 4 — Performance (done, awaiting headset check)
Measured texture memory (scene textures + shadow map, mips counted, Quest path `?q=xr`): about 454 MB before, 208 MB after. Biggest wins were not in the roadmap list.
- Terrace reflection map: was a 96 MB PMREM made from the 4k sky; now made from a 1024-wide HDR copy (6 MB). `__envSmall` must copy `flipY` (the UltraHDR loader sets it) or the reflection is upside down.
- Sky: on Quest (`nm==="xr"`) the HDR sky is box-filtered 4096x2048 -> 2048x1024 in linear half-float at load (`__halfImg`), 64 -> 16 MB. Desktop keeps 4k. The .hdr.jpg is a gain-map JPEG; never re-save it with an image tool.
- Files resized (linear-light Lanczos; normal maps renormalised): oak 4096x1024 -> 2048x512, concrete 2048 -> 1024 (diff, nor, orm).
- Already present, verified: shadow maps update only on demand (`autoUpdate=false`), physics bodies sleep (`setCanSleep(true)`), textures loaded once per URL and shared.
- New `addons/perf.js`: warning at 80 physics props, new spawns refused at 100 (Game Editor `addThrowable`, object-script `spawnCopy`); storage `perf.propLimit=off` disables the stop. Foveation 0.5 in VR, 0.75 when the Profiler average frame time is over 12.5 ms for 2 s, back after 15 s under 9.5 ms.
- Bundle: `window.__studio.profiler` exposed; `spawnCopy` checks `__studioProps.full()`.
Still above the 120 MB target: the 1k model textures (lamp, plant, clock, pistol, ~64 MB) and 8-bit textures in general. Getting under 120 MB without losing detail needs KTX2/UASTC (about 4x less memory at the same resolution).
